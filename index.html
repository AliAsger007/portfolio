~/about

Records, rules, and the code underneath.

I'm an MCA student at Bharati Vidyapeeth's IMED in Pune, and a 2025 BCA graduate from Aishwarya College of Education Sansthan in Udaipur. I grew up in Salumber, a small town in Rajasthan — which is probably why I still find it slightly surprising that a form on a screen can update a record a real college runs on.

For my BCA final-year project I built a Student Management System on my own. A new student registers, and the system generates their unique student ID and roll number. From then on their student portal shows the courses they're enrolled in, the exams coming up, and any backlog papers they still need to clear. The admin side is where those records are created and updated — students, courses, exam schedules, backlogs. The interface is HTML, CSS and JavaScript; the data lives in Microsoft SQL Server.

The part I enjoyed most wasn't the screens. It was deciding what the database should refuse to allow: what keeps a roll number unique, how a backlog is tied to both a student and a subject, what happens when an admin corrects a record. That's the kind of work I want more of, and it's why I'm aiming at data engineering rather than front-end only.

~/work

One project taken all the way through: the data model, the admin side, the student side, and the awkward cases in between.

BCA final-year project · Solo · 2025

Student Management System

Completed

A web application that runs a college's student records. Students register, receive a generated ID and roll number, then open a student portal showing their courses, upcoming exams and backlog papers. An admin dashboard maintains the records behind it.

  1. 01 Register New student submits their details
  2. 02 Generate Unique student ID and roll number issued
  3. 03 Admin Courses, exams and backlogs are recorded
  4. 04 Student portal Courses, exams and backlogs in one view

Two modules, one system

Student portal
  • Student ID and roll number, as issued
  • Enrolled course details
  • Upcoming exams and their dates
  • Backlog papers awaiting re-examination
Admin dashboard
  • Adds and updates student records
  • Manages courses and subjects
  • Schedules exams, including backlog re-exams
  • Feeds every view in the student portal
